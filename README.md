# 🛂 签证护照办理助手（静态小程序）

纯前端静态页面，**无需后端、无需构建**，可直接部署到 GitHub Pages。

覆盖 **申根 / 美国 / 加拿大 / 澳大利亚** 等四类热门签证，外加 16 个热门国家/地区（日韩英新泰马、印尼、越南、印度、阿联酋、土耳其、俄罗斯、埃及、肯尼亚、阿根廷、新西兰），并提供：

- ✅ **交互式签证世界地图（状态驱动配色）**：没有申请记录时只有 🔴红=中国护照免签/落地签 和 ⚪灰=暂不可去；在「进度跟踪」添加申请后地图才会点亮 —— 🔵蓝=办理中的签证国、对应大区浅色=持签可去（出签后变紫）、🟣紫=已出签解锁地区、🟡🟢🩵🟠=已出签的申根/美/加/澳签证区本身；拒签视同没有申请。点击国家放大查看（再点复位），支持一键全屏并在竖屏下自动横屏展示
- ✅ **粉丝口令解锁**：在 `data.js` 的 `FAN_GATE` 中配置口令，粉丝输入口令后使用（口令发布在抖音/小红书置顶作品简介）
- ✅ 材料清单、费用、审理时长、有效期 + 搜索和地区分组
- ✅ 一键跳转各国官方签证申请网站（France-Visas、CEAC/DS-160、IRCC、ImmiAccount 等）
- ✅ 签证办理进度跟踪（数据保存在浏览器 localStorage，非 Cookie，不上传服务器）
- ✅ 持有效美签 / 加签 / 澳签 / 申根签可免签或简化入境的国家和地区 + 热门城市
- ✅ 中国护照免签 / 落地签参考列表

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（如 `visa-assistant`）
2. 把 `index.html`、`style.css`、`data.js`、`mapdata.js`、`app.js` 上传到仓库根目录
3. 打开仓库 **Settings → Pages**，Source 选择 `main` 分支 / `/ (root)` 目录，保存
4. 稍等 1–2 分钟，访问 `https://你的用户名.github.io/visa-assistant/` 即可

> 也可以直接用 GitHub 网页端的 "Upload files" 拖拽上传，全程不需要命令行。

## 本地预览

直接双击 `index.html` 用浏览器打开即可。

## 文件结构

```
visa-assistant/
├── index.html   # 页面结构（4 个标签页 + 世界地图）
├── style.css    # 小程序风格样式（移动端优先）
├── data.js      # 签证数据、目的地数据、地图映射（想改内容只改这里）
├── mapdata.js   # 世界地图 SVG 路径（由 world-atlas 110m TopoJSON 生成）
└── app.js       # 页面逻辑 + localStorage 进度跟踪 + 地图渲染
```
